# Repository scope

EnronQA-cli is a self-contained tool. Keep runtime code, product tests,
packaging, user documentation, and CLI specifications here. Do not add research
experiments, model comparisons, benchmark-run artifacts, question-reformulation
audits, or research reports to this repository. Those belong in a separate
research project. Product implementation issues belong here; research issues
belong in their research repository.

Explicit user decision, September 11, 2026: "stop putting experiments in the
CLI, the CLI is going to be a self-contained tool and we'll do our experiments
elsewhere".

Use uv for Python commands and development.
